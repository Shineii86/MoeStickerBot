## 🎯 Обзор

**Moe Sticker Bot** — это мощный Telegram-бот, написанный на Go, который позволяет вам:

- 📥 **Импортировать** наборы стикеров LINE и KakaoTalk напрямую в Telegram
- 🎨 **Создавать** собственные наборы стикеров из любых изображений или видео
- 🛠️ **Управлять** стикерами с помощью красивого WebApp с перетаскиванием *(опционально)*
- 💾 **Скачивать** стикеры Telegram в различных форматах (PNG, WebP, GIF, WEBM)

Данное **Google Colab Издание** объединяет всю установку в один ноутбук. Оно устанавливает все зависимости, компилирует бота из исходного кода и запускает его в фоновом режиме — VPS или Docker не требуются. Идеально для тестирования, личного использования или просто для развлечения со стикерами.

> [!NOTE]
>  Бесплатные сессии Colab отключаются после ~90 минут бездействия. Для круглосуточного хостинга рассмотрите использование VPS или официального Docker-образа.

## 🛠️ Предварительные требования

Вам нужны только две вещи:

1. **Аккаунт Google** (для Colab)
2. **Токен Telegram-бота** (от [@BotFather](https://t.me/BotFather))

### 🔐 Создание токена Telegram-бота

1. Откройте Telegram и найдите **@BotFather**.
2. Отправьте команду `/newbot`.
3. Выберите **имя** для бота (например, `Мой Стикер Бот`).
4. Выберите **имя пользователя**, оканчивающееся на `bot` (например, `my_sticker_bot`).
5. BotFather выдаст вам токен вида:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
6. **Скопируйте этот токен** — он понадобится на этапе настройки.

> 🔒 **Храните токен в секрете!** Любой, у кого он есть, может управлять вашим ботом.

## 🌐 Опционально: Включение WebApp (ngrok)

Менеджер WebApp требует публичный HTTPS URL, который Colab не предоставляет. В ноутбук встроена поддержка **ngrok** для создания безопасного туннеля.

### Как включить

1. **Зарегистрируйте бесплатный аккаунт ngrok** на [ngrok.com](https://ngrok.com/).
2. Скопируйте ваш **authtoken** из [панели управления](https://dashboard.ngrok.com/auth).
3. В ячейке **Конфигурации**:
   - Установите `ENABLE_WEBAPP = True`
   - Вставьте ваш токен в `NGROK_AUTHTOKEN`
   - (Опционально) Измените `WEBAPP_PORT`, если нужно
4. Запустите все ячейки. Ноутбук автоматически:
   - Скачает и установит ngrok
   - Запустит туннель к порту WebApp
   - Получит публичный `https://` URL
   - Передаст его боту через `--webapp_url`

> [!NOTE]
> Бесплатные URL ngrok временны и меняются каждую сессию. При перезапуске среды Colab настройку придется повторить.

## ⚙️ Справочник по конфигурации

Ноутбук предоставляет следующие параметры конфигурации:

| Поле | Обязательно | Описание |
|-------|----------|-------------|
| `BOT_TOKEN` | ✅ Да | Ваш токен Telegram-бота |
| `ENABLE_DB` | ❌ Нет | Включить MariaDB для общих наборов стикеров |
| `DB_ADDR` / `DB_USER` / `DB_PASS` | Только если БД включена | Данные для подключения к базе данных |
| `ENABLE_WEBAPP` | ❌ Нет | Включить поддержку WebApp через ngrok |
| `WEBAPP_PORT` | Только если WebApp | Порт для внутреннего сервера WebApp (по умолчанию: 8080) |
| `NGROK_AUTHTOKEN` | Только если WebApp | Ваш бесплатный authtoken ngrok |
| `DATA_DIR` | ❌ Нет | Папка для хранения данных бота |
| `LOG_LEVEL` | ❌ Нет | `debug`, `info`, `warn` или `error` |
| `HTTP_PROXY` | ❌ Нет | URL прокси, если необходимо |

## 🔧 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| **"Бот завершился сразу"** | Проверьте `bot_stderr.log`. Частая причина: неверный формат токена. |
| **Предупреждение о missing exiv2** | Перезапустите ячейку с зависимостями: `!apt-get install -y exiv2` |
| **Бот останавливается через ~90 минут** | Это нормально для бесплатного Colab. Держите вкладку активной или используйте Colab Pro. |
| **WebApp не работает** | Убедитесь, что `ENABLE_WEBAPP = True` и указан корректный `NGROK_AUTHTOKEN`. |
| **Не удалось получить URL ngrok** | Проверьте правильность токена ngrok и доступность порта `4040`. |
| **Предупреждение "Database not enabled"** | Это нормально — бот полностью работает без базы данных. |

Для более детальных логов установите `LOG_LEVEL = "debug"` в ячейке Конфигурации.

### В: Это действительно бесплатно?

> **О:** Конечно! Отправьте боту любое изображение или видео, и он проведет вас через обрезку, изменение размера и конвертацию.

### В: Поддерживаются ли анимированные стикеры?
> **О:** Да! Бот конвертирует видео в формат WebM и поддерживает как статичные, так и анимированные стикеры в одном наборе.
